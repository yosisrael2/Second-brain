## Design
- `src/brain/services/dedupe.py`: normalize_text (NFKC → strip RTL marks → collapse whitespace → casefold),
  content_fingerprint(raw_text, occurred_at, source) = sha256(norm + \x1f + UTC-minute + \x1f + source).
- MemoryItem: `fingerprint` String(64) nullable, indexed; plain class attr `deduplicated: bool = False`
  (transient flag; NOT a column).
- ItemsRepository.get_by_fingerprint (+Proto, +FakeRepository).
- IngestService.create: fp lookup BEFORE insert → hit: ops.record_event("ingest","dedupe_hit"), set
  existing.deduplicated=True, return existing (no insert/classify/index/commit).
- ItemRead.deduplicated: bool = False (pydantic from_attributes falls back to default when attr absent).
- ONE migration (down_revision=c7d91e4a2b58): occurred_at type repair + fingerprint col + ix + Python backfill
  (imports brain.services.dedupe.content_fingerprint for consistency).
- paste.py `_calendar_one_liner(meta, zone)`: "<title> — <Day DD Mon HH:MM–HH:MM> @ <location>" (en dash between
  times, em dash after title). _parse_ics: meta['ics_raw']=full ICS, raw_text=one-liner.
  _parse_calendar_text: meta['original_text']=text, raw_text=one-liner (consistency; justify in PR).
- CLI `brain normalize-calendar`: rewrite source=calendar items (one-liner from meta, keep ics_raw/original_text,
  recompute fingerprint). NO reindex inside CLI (manager's deploy order does `brain reindex` separately).
